# mamutchetoned.github.io

`c.html` is the appointment confirmation page for DentalApp: the `{confirm_link}`
in the patient SMS opens `https://mamutchetoned.github.io/c#<token>`.

Built from `web/confirm.html` in the DentalApp repo with `node web/build.mjs`;
don't edit it here. It contains only the public (publishable) Supabase key.
